## 실측

- 1,000행/쿼리 · 평균 2.6초 · 창구 한도 **시간당 120회** = 최대 12만 행/시간
- 적재 중 로그인 화면 **200 정상**(0.13~3.76초). DB 용량 60MB → 예상 250MB 안팎
- 🔴 **한도(120/시간)를 올리지 말 것.** 예전에 600으로 올려 몰아쳤다가 DB가 뻗었다. 이 한도가 브레이크다.

## 이어서 할 때

```
python3 load.py 인도네시아 53000 40000 1000
```
CSV 원본은 `agoda_file_source` 표의 한국어(KO) 주소에서 다시 받는다(421MB zip → 1.9GB csv, 다운로드 약 2분).
⚠ **이 적재는 사람이 돌린다.** 파일이 1.9GB라 서버 봇이 다룰 수 없다. 한 번 하면 끝나는 일이다.
