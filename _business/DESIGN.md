## 0. 왜 이 색인가 (근거 — 다음 클로드가 되돌리지 않게)

대표님(2026-09-03): *"색깔도 왜 초록 보라색으로 한정하는 거야? 로고색이랑 안 같아도 된다."*

```
옛 보라(#7C3AED)+초록은 «기존 라이브 Aurora 톤 유지»(D-057)로 물려받은 것뿐,
«이 색이어야 하는 이유»가 없었다. 로고(청록)와도 이미 어긋나 있었다.
게다가 «어두운 배경 + 형광 한 색»은 AI 가 뽑는 뻔한 형태로 지목된 조합이다.

새 기준 = 「호텔 사장이 신뢰하는 색」
  Booking.com 진한 파랑 · 아고다 파랑+보라 · Expedia 남색+노랑 → 여행 B2B 는 파랑 계열이 압도적
  → 배경은 깊은 남색으로 «업계 사람»처럼 보이게 하고,
     강조는 앰버로 그 파랑 무리에서 «혼자 튀게» 한다.
     앰버는 호텔 로비 조명·황금빛 = 업종의 언어이고, 숫자에 얹으면 «수익»으로 읽힌다.
```

🔴 **주인공 색은 하나뿐이다.** 옛 화면은 버튼 보라·돈 초록·로고 청록으로 셋이라 힘이 흩어졌다.
앰버는 **CTA 와 핵심 숫자에만** 쓴다. 나머지는 전부 무채색.

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `--bg` | `#0B1220` | 페이지 바탕 (깊은 남색) |

| `--line` | `rgba(255,255,255,0.10)` | 구분선·테두리 |
| `--ink` | `#F2F5FA` | 본문 글자 |

| `--amber-deep` | `#C97F10` | 앰버 위 글자·눌림 상태 |
| `--amber-soft` | `rgba(245,165,36,0.12)` | 앰버 배경 은은하게 (박스 채움) |

### 🔴 쓰지 않는 것
```
보라 #7C3AED · 초록 #4edea3 · 청록 #22D3EE   — 2026-09-03 폐기 (D-108)
핑크 · 주황(앰버 외) · 빨강(오류 표시 제외)
그라데이션 글자 — 섹션마다 넣지 않는다. 써도 페이지 전체에 한 곳
```

### 앰버 사용 규칙 (엄격)
```
① 한 화면에 앰버는 «두 곳까지». 세 곳이면 하나를 무채색으로 내린다
② CTA 버튼 = 앰버 채움 + 남색 글자(#0B1220). 테두리형 버튼은 무채색
③ 핵심 숫자 하나만 앰버. 같은 섹션의 다른 숫자는 흰색
④ 돈(환불·금액)에 초록을 쓰지 않는다 — 앰버가 그 역할을 겸한다
```

## 2. 글꼴

| 용도 | 글꼴 | 비고 |
|---|---|---|
| 제목 | **Montserrat** 700/600 | 영문 기준으로 자간 -0.02em |
| 본문(영문) | **Inter** 400/500 | |
| 🔴 본문·제목(한글) | **Pretendard** | Inter 로 한글을 찍으면 무너진다 |
| 숫자 | Montserrat, `font-variant-numeric: tabular-nums` | 자릿수 흔들림 방지 |

### 🔴 한글 필수 규칙
```css
:lang(ko), [data-ko] { word-break: keep-all; overflow-wrap: break-word; }
```
2026-09-03 시안에서 「한국 손님이 예약하 / 지 않을까요?」로 **단어가 중간에서 잘렸다.**
한국어는 단어를 쪼개지 않는다. 이 한 줄이 빠지면 화면이 싸구려가 된다.

### 크기 (모바일 → 데스크톱)
```
히어로 제목   32px → 56px    행간 1.15
섹션 제목     24px → 40px    행간 1.2
큰 숫자       40px → 88px    행간 1.0
본문          15px → 17px    행간 1.65
보조·라벨     12px → 13px
```
한 줄은 **80자 이하**. 영문 기준으로 여백을 잡되 한글에서 깨지지 않는지 반드시 확인한다.
