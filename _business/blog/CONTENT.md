## 0. 큰 그림 (왜 이 작업을 하는가)
지금 포맷별 내부 구성을 잡는 이유 = **자동화의 "틀"**을 먼저 확정하기 위함.
틀 확정 → 검색·기획·제작·검수·발행 자동화 → 엔진 복제(다른 니치 블로그, 유형만 교체).
정합: 엔진 1벌+도메인 N개(D-B03) · 나라×도시×포맷 무한소재(D-B08) · 반자동+사람검수(D-B09).

## 1. 자동 콘텐츠 공장 (한 편이 만들어지는 길)
1. **검색** — 실예약 큰데 글 없는 도시·키워드 (api/content-keywords.js, D-B08)
2. **기획** — 11포맷 중 선택 + 후킹 제목 (D-B07)
3. **제작** — 본문·사진·아고다 예약링크(R코드) 생성 (D-B05 종합, 복제 아님)
4. **검수(사람)** — 발행 전 질 확인, 무인 양산 금지 (D-B09)
5. **발행** — 정적 배포 → staycurate.com
6. **측정·돈** — 예약·전환 상황판(D-B12) → 다음 검색에 반영(루프)

## 2. 콘텐츠 포맷 11종 (D-B07 정본) — "돈 되는 순" 3그룹
> ⚠️ "단일 숙소 리뷰"는 정본 11종에 **없음**(2026-08-05 임의 제안 철회). 리뷰 성격은 "후기종합"으로 흡수.

**A. 돈 바로 되는 (예약 직결) — 최우선**
- 베스트목록 — "오사카 호텔 베스트 15" (검색 최다·즉시 예약)
- 동네가이드 — "오사카 어디서 잘까" (동네별 추천)
- 목적별 — "아이랑 좋은 오사카 호텔" (목적 뚜렷=예약 빠름)
- **예산분해 — "오사카 호텔 10만원대 / 10만원 미만" (2026-08-05 대표님 지시로 B→A 승격. 가격은 여행자가 가장 먼저 정하는 조건이라 예약 전환 빠름)**

**B. 예약 도와주는 (결정 직전)**
- 동네비교 "난바 vs 우메다" · 후기종합 "여기 진짜 어때?" · 완벽가이드(도시 숙소 총정리 허브)

**C. 사람 불러오는 (초기 유입·신뢰, 예약은 간접)**
- N일일정 · 가기좋은시기 · 예약실수 · 꿀팁핵
- 역할: 검색 유입 → A·B 글로 보내는 내부링크(D-B12 기여전환)

## 2-2. 디자인 톤 규칙 (전 화면 공통)
- **이모지 금지** — 알록달록 이모지는 "AI가 붙여넣은" 인상. 조용한 큐레이션 톤과 안 맞음. 아이콘은 얇은 선(SVG) 또는 글자만.
- 브라스 금색은 포인트에만 소량. 여백 넉넉. (D-B16 정합)

## 2-3. 포맷별 아이템 개수 기준 (2026-08-05 확정 · C안)
개수는 포맷 성격에 맞춘다. 15개 일괄은 읽기 피로·제작 부담이 커서 금지.
| 포맷 | 개수 | 이유 |
|---|---|---|
| 베스트목록 | **7개** | 검색 클릭 유리 + 지치지 않는 균형 |
| 목적별 | **5개** | 목적이 좁아 적을수록 선명 |
| 예산분해 | 가격대 **3~4구간 × 각 3~4곳** | 구간별 비교가 핵심 |
| 동네가이드 | 동네 5~6 × 동네당 2~3곳 | 동네가 주인공 |
| 완벽가이드(허브) | 12~15개 | 도시 총정리 성격 |
| 동네비교 | 2~3곳 대결 | 비교가 핵심 |
| 후기종합 | 1곳 심층 | 깊이 |

## 2-4. 예산분해 포맷 내부 구성 (대표님 요청 2026-08-05)
- 제목형: "오사카 호텔 예산별 정리 — 10만원 미만부터 30만원대까지"
- 구간 예시(도시별 조정): **10만원 미만 · 10만원대 · 20만원대 · 30만원 이상**
- 구간마다: 구간 요약 한 줄(이 가격대는 뭘 포기하고 뭘 얻나) → 호텔 3~4곳(사진·평점·좋아요/아쉬워요·[아고다]) 
- 상단: 예산 빠른 이동 버튼(구간 점프) · 하단: 가격대별 한눈 비교표
- 주의: 가격은 변동값 → "참고값·예약 시점에 따라 달라짐" 고지 필수

## 2-5. 이미지 출처 규칙 (2026-08-05 확정 · 위반 금지)
| 용도 | 허용 출처 | 비고 |
|---|---|---|
| **호텔 사진** | 아고다 API(`imageURL`, Content Feed 최대 20장/호텔) · 호텔 공식 제공 · 직접 촬영 | **무료 스톡 금지.** 다른 호텔 사진을 붙이면 기만·클레임·신뢰 붕괴 |
| 명소·도시·분위기 | Unsplash 등 무료 라이선스(상업적 사용 가능) | 도톤보리·오사카성 등 |
| 저장 방식 | **사진 주소(URL)만 DB 저장**, 파일 다운로드·재배포 안 함 | 용량 0·자동 갱신·저작권 안전 |
⚠️ 현재 샘플 페이지의 호텔 사진은 **임시 스톡**. 파이프라인(로드맵 4-b) 완료 시 전량 교체 필수.

## 3. 공통 "돈 장치" (모든 포맷)
- 각 호텔마다 **[아고다 예약] 버튼 = R코드**(gohpik.com/r/{코드}) · 상단·하단 반복
- 좋아요/아쉬워요 **균형**(단점도 솔직 = 신뢰, D-B06)
- **사진**(아고다·공식 제공분, D-B05) — 시각이 전환을 만든다
- 상단 **3초 요약** · 관련 글 내부링크(A↔B↔C 순환)
- 애드센스는 통장 붙기 전 OFF, 아고다만(D-B04)

## 6. 근거 (리서치)
- 숙소 콘텐츠 = 여행 어필리에이트 최고 전환. 아고다·Booking은 동네가이드·호텔모음·도시가이드에 강함.
- 전환 포맷: 베스트목록·가격비교·특가·pros/cons 리뷰.
- 대형 매체(Time Out 등) 실제 구성 = [도시]×[베스트/가성비/동네가이드/유형] → 우리 11포맷과 일치.
- 여행자는 수주 리서치 후 예약 → 초기 정보형(C그룹)도 기여전환으로 가치.
