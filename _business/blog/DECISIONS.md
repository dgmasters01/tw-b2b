# TW 여행 블로그 — DECISIONS (2026-08-03 세션)

블로그는 tw-b2b와 별개 사업. 아래는 오늘 확정한 결정.

## D-B01 사업모델 = 데이터 종합형 추천 미디어 + 어필리에이트
공개 데이터(가격·평점·후기) 종합 + 우리 실적 데이터 → 추천 → R코드 예약 → 커미션+애드센스. Wirecutter·NerdWallet이 검증한 모델. 근거: 두 회사 모두 어필리에이트 기반, 데이터 기반 추천 엔진, 카테고리 확장.

## D-B02 보안 = B2B와 완전 격리
블로그는 tw-b2b와 별도 Vercel 프로젝트·별도 레포. 같은 계정 안. 블로그엔 결제·고객DB·서비스롤·ops토큰 등 민감키 0개. R코드는 gohpik.com/r/{코드} 링크만 심어 재활용(블로그가 Supabase 직접 안 만짐). 이유: 공개 블로그 취약점이 B2B 자산에 닿으면 안 됨.

## D-B03 플랫폼 = 자체 정적 (멀티 엔진)
Vercel Pro 기존 계정 그대로(새 아이디·추가 월정액 없음, 도메인 사실상 무제한). 빌드 없는 정적 HTML. 엔진 1벌 + 도메인 N개(멀티테넌트). WordPress/Ghost 대비: 자산 직결 + 유지비 0 + 개발은 Claude가 함. 근거: 정적 사이트가 속도·GEO에 유리, 플랫폼 아닌 콘텐츠가 노출을 결정.

## D-B04 수익 = 아고다 제휴(주) + 애드센스(보조)
아고다는 cid·R코드로 명의 이슈 없음(메인). 애드센스는 보조. 애드센스 여러 명의 분배 시 = 진짜 용역구조(통제권+통장 모두 그 사람)여야 정책·세무 안전. 명의만 빌리는 형태는 리스크. 통장은 처음부터 받을 사람 것으로, 통제권은 나중 이관 가능. 애드센스 통장 붙기 전엔 광고 끄고 아고다만.

## D-B05 콘텐츠 = 후기 종합 + 우리 데이터
여러 출처 후기를 읽고 **사실·평판 패턴을 우리 문장으로 종합**(복제·스핀 아님). + 호텔DB·R코드 실적. 근거: 구글 "대량 콘텐츠 남용"은 독창성 없는 복제를 벌함. 종합+1차데이터는 E-E-A-T의 경험 신호가 됨. 인스타 등은 최신정보·트렌드 파악용(콘텐츠·사진 복제 금지). 사진은 아고다·공식 제공분(어필리에이트 허용)·라이선스·직접촬영만.

## D-B06 톤·UX = 친근한 큐레이터 + 시각 중심
친근한 말투, 하지만 거짓 1인칭("내가 가봤다") 금지 → "투숙객 후기 다수" 정직 화자. 좋아요/아쉬워요 균형(단점도 솔직히=신뢰). 텍스트 최소·스캔 가능. 주변 맛집·명소+거리(도보/차) 포함. 상단 3초 요약.

## D-B07 포맷 라이브러리 11종 + 후킹

## D-B08 구조 = 나라 > 도시 > 포맷 3층

## D-B09 발행 = 지속가능한 질
