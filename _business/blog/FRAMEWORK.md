> 원칙: "화면 먼저"가 아니라 "이 틀 먼저". 정석대로, 순서대로, 하나씩 제작한다.

## 0. 지금 상태 (냉정하게)
- 있는 것: 홈(퍼블리셔형) · 글 상세 1편(동네 가이드) · 메뉴 버튼 3축 · 반응형(웹+모바일).
- 없는 것: 아래 8기둥 중 ②·③ 전체, ①의 카테고리 목록·검색.
- 즉 "모델하우스" 단계 → 운영 가능한 블로그로 만들려면 이 틀을 순서대로 채운다.

## 1. 8기둥 (정석 블로그가 기본으로 갖는 것)
1. 페이지 골격(정보구조) — 홈·목록·글·검색·오류
2. 신뢰(E-E-A-T) — 저자·소개·편집/정정 정책·업데이트 표기
3. 법적·고지 — 개인정보·이용약관·연락처·제휴 고지
4. 검색·AI 뼈대 — sitemap·robots·rss·ads.txt·llms.txt·구조화 데이터(JSON-LD)·OG·canonical
5. 읽기 편의 — 브레드크럼·목차·관련글·공유·뉴스레터·지도·비교표
6. 수익 — 아고다 예약 링크·(추후)애드센스 슬롯·딥링크
7. 측정 — GA4·Search Console·예약 성과 대시보드
8. 서버·주소 — 별도 레포 + 별도 Vercel 프로젝트 격리 + staycurate.com 연결 (민감키 0)

## 2. 전체 페이지 트리 (URL + 담는 것)
- `/` 홈 — 오늘의 추천 + 카테고리 섹션 피드
- `/destinations` 여행지 허브 — 대륙→나라→도시
  - `/destinations/{country}` 나라 — 그 나라 도시 목록
  - `/destinations/{country}/{city}` 도시 — 그 도시 글 목록(아카이브)
- `/topics` 주제 허브 → `/topics/{style}` (가성비·가족·커플·혼자·럭셔리·출장)
- `/guides` 가이드 허브 → `/guides/{slug}` (예약팁·실수·예산·시기·처음)
- `/{city}/{slug}` 글 상세 (동네 가이드 등 여러 포맷)
- `/search` 검색 결과
- `/authors` · `/authors/{name}` 저자 페이지 (E-E-A-T)
- `/about` 소개 · `/contact` 연락처 · `/editorial-policy` 편집·정정 정책
- `/privacy` 개인정보처리방침 · `/terms` 이용약관 · `/affiliate-disclosure` 제휴 고지
- `/404` 오류 페이지
- 시스템 파일: `/sitemap.xml` `/robots.txt` `/rss.xml` `/ads.txt` `/llms.txt`

## 3. 글 상세 내부 정석 순서 (모든 글 공통)
헤더 → **제휴 고지(맨 위, 명확한 한국어)** → 브레드크럼 → H1 제목 →
저자·발행일·**업데이트일**·읽는시간 → 목차 → 대표사진(출처 표기) →
후크 → 3초 요약 → 본문(동네 섹션[호텔카드+주변+지도]×N) →
관련글 → 저자 박스 → 공유 → 뉴스레터 → 푸터.
+ 구조화 데이터: Article / BreadcrumbList / (Hotel·ItemList) / Person / Organization.

## 4. 제휴 고지 표준 (한국 공정위 추천·보증 심사지침 근거)
- 위치: **글 제목 바로 아래 / 첫 부분.** 끝부분·더보기·댓글 금지.
- 언어: 한국어. 글자색·크기 잘 보이게.
- 조건부·불확정 표현 금지("수수료를 받을 수 있음" 류는 부적절).
- 표준 문구(예): "이 글에는 제휴 링크가 포함되어 있으며, 링크를 통해 예약하면 staycurate가 수수료를 받습니다. 가격은 오르지 않습니다."
- 근거: 공정위 추천·보증 심사지침 — 문자 매체는 제목/첫 부분에 표시, 조건부 표현 부적절.

## 5. 신뢰(E-E-A-T) 필수 요소 (2026 기준)
- 실명/필명 저자 + 소개·경력·사진 + 저자 페이지(그 저자 글 모음).
- 편집·정정 정책 페이지, 각 글 **업데이트일** 표기.
- 근거: 2026 구글 업데이트에서 저자·경험·편집 투명성이 랭킹에 크게 작용. 익명 어필리에이트는 감점.
- AI 활용 시 "사람 검수" 명시(투명성).

## 6. 광고·법적 필수 페이지 (AdSense 승인 근거)
- 소개 / 연락처 / 개인정보처리방침(쿠키·구글 애드센스 명시) / 이용약관 — 없으면 승인 반려.
- 푸터·메뉴에서 쉽게 접근.

## 7. 제작 순서 (하나씩)
1. ✅ 전체 틀(이 문서) 확정
2. 공통 뼈대(레이아웃 시스템: 헤더·푸터·메뉴·색·글꼴) 컴포넌트화
3. ① 콘텐츠: 카테고리 목록(아카이브) 페이지 → 검색 결과 페이지
4. ② 신뢰·법적: 소개·연락처·편집정책·개인정보·이용약관·제휴고지 (실제 문구)
5. ③ 시스템·SEO: robots·sitemap·rss·ads.txt·llms.txt·JSON-LD·OG·404
6. 읽기 편의(브레드크럼·목차·관련글·공유·뉴스레터·지도)
7. 측정(GA4·GSC·성과 대시보드) 연결
8. 서버 격리(별도 레포+별도 Vercel) + staycurate.com 연결 — Vercel 도구 세션에서
9. 첫 글 1편 손으로 제작 → 표준 템플릿화

## 8. 근거 출처(요약)
- 필수 페이지·기능: 여행 어필리에이트 블로그 표준(소개·개인정보·제휴고지·뉴스레터·지도·비교표).
- E-E-A-T: 2026 구글 업데이트(저자·편집·업데이트가 랭킹 인프라).
- 제휴 고지: 한국 공정위 추천·보증 심사지침(제목/첫 부분·명확 표현).
- 광고 승인: AdSense 필수 페이지(소개·연락처·개인정보[쿠키·애드센스]·약관).
