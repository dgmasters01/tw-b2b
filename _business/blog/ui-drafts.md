# 블로그 UI 초안 (세부 포맷 단계에서 확정)

## 글 상세 화면 (동네 가이드 포맷) v1 — 2026-08-03 · 임시저장
상태: 초안 완료, 승인 대기. **콘텐츠 세부 포맷 단계에서 확정.** (지금은 메인 UX 먼저)

구성 순서(모바일):
헤더(로고+메뉴) → H1 제목 → 메타(날짜·읽는시간·제휴고지) → 대표사진(아고다/공식) → 후크 인트로 → "바쁘면 여기만" 3초 요약박스(동네별 Best pick) → 동네 섹션[동네명 + "OOO에게 최고" 태그 + 친근 설명 + 호텔카드(사진·평점·좋아요/아쉬워요·가격·예약버튼) + 이 동네 가볼곳(거리 도보/차 표시)] × N개 → 관련 유튜브 임베드 → 푸터(소개·연락처·개인정보·제휴고지 작은 링크).

원칙: 모바일 우선 · 텍스트 최소 · 예약버튼(R코드) 강조 · 친근 큐레이터 톤(거짓 1인칭 금지) · 사진=아고다/공식/라이선스.
