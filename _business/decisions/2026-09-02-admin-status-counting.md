# D-103 · 「시스템 완성도」 화면은 **세는 법**부터 고친다

**날짜** 2026-09-03 · **카테고리** ux · **상태** 확정

> ⚠️ **작성일 정정**: 이 결정의 실제 날짜는 **2026-09-03** 이다. 파일명의 `2026-09-02` 는 클로드 실행 환경의 시계가 하루 늦어 생긴 것으로, 경로가 여러 문서에 걸려 있어 파일명은 그대로 둔다. 🔴 **다음 클로드에게: 날짜를 적기 전에 컨테이너 `date` 를 믿지 말고 창구 응답의 시각(`quota.window_reset_at`)이나 대표님 화면 시각으로 대조하라.**

**짝 결정** D-039(화면 역할 헌법) · **대상** `_admin/admin-status.html` · `tasks.json`

## 대표님 지시
> *"대표님 눈을 어둡게 만드는 제안은 하지 마라. 화면은 더 신선해져야 한다."*
> *"상태가 안 보이면 작업이 되는지 모른다 — 눈은 줄이지 않는다."*

## 무슨 일이 있었나
화면이 「막힘 31건 · 대표님 결정 19건」을 띄우고 있었다. 실제 내용을 뽑아보니 **겁주는 숫자였다.**

| 섞여 있던 것 | 건수 | 실제 |
|---|---|---|
| 이미 취소·흡소·폐기된 작업 | 3 | `BL-SERVICE-PAGE-MAP`(obsoleted) · `BL-SUPABASE-SQL-AUTO-APPLY`(cancelled) · `BL-CAPTURE-BOT-RESTORE`(absorbed) |
| 이미 결정이 끝났는데 표시가 안 지워진 것 | 2 | `BL-OS-INSTALL-PAT-FLOW`(05-13 결정문 존재) · `BL-YT-VIEWS-COLLECT`(크론 매시 :00 가동 실측) |
| 오픈 전이라 결정 자체가 불가능한 것 | 8 | BL-004·005·007·012·013 · SQ-D·E·F — 사이트 미오픈·가입 매니저 0명 |
| 조건이 와야 착수하는 것 | 1 | `BL-STUDIO-MENU-6TAB` — 11단계 중 10단계 완료, 남은 1칸은 «새 채널 추가 시» |
| 🔑 진짜 대표님 몫 | 2 | `BL-BOOKING-EARNINGS-IMPORT`(아고다 수수료 리포트) · `BL-YT-DRIVE-WATCH`(구글 서비스계정 키) |

## 🔴 근본 원인 — 한 화면 안에서 두 함수가 서로 다르게 셌다
`plDecisionNeeded()` 는 이미 `cancelled`/`obsoleted`/`absorbed` 를 제외하고 있었는데,
`renderIntegratedKPI()` 와 `renderCeoWait()` 는 `status !== 'done'` 하나로만 걸렀다.
**«미완료» 의 정의가 코드 안에서 갈라져 있었다.**

## 정한 것
1. **미완료 판정을 한 곳으로** — `CLOSED_STATUS = ['done','cancelled','obsoleted','absorbed']`. 세 함수가 같은 기준을 쓴다
2. **막힘은 숨기지 않고 «나눈다»** — 카드 숫자는 진짜 막힘만, 바로 아래 줄에 `🔑 대표님 몫 N · ⏳ 오픈 대기 N · ⏸ 조건 대기 N` 을 항상 함께 띄운다. 🔴 지우는 게 아니라 서랍을 나누는 것이다
3. **분류는 화면 코드가 아니라 `tasks.json` 에 단다** — `gate: 'service_open' | 'owner_action'` + `gate_note`. 정본이 먼저다
4. **데드라인 정본은 `tasks.json` 하나** — 코드에 박힌 `const DEADLINE = '2026-06-30'` 과 `tasks.json` 의 `2026-05-03` 이 한 화면에서 싸우고 있었다. 코드는 폴백만 갖고 로드 시 정본으로 덮어쓴다
5. **`waiting_trigger` 상태 신설** — 조건이 와야 착수하는 작업. 「진행 중」에서 빠지고 「잠시 멈춤」으로 내려가되 **사라지지 않는다**

## 함께 드러난 것 — 안전망이 절반만 지키고 있었다
관리자 화면 무결성 기준선이 **2026-05-07 에 멈춰 8장만** 감시했다.
그 뒤 만든 **7장(인보이스·설정·의사결정 이력/인덱스·비즈니스 헌장·매니저 여정·사용자 여정)이 무방비**였다.

노란 경고 「5개가 원본과 다르다」의 5개를 전수 대조한 결과 — **사고 0건, 전부 의도된 개발**이었다.

| `admin.html` | 1,287KB → 410KB | 용량은 줄었으나 **줄 4,676→6,846 · 기능 144→197개** — 정리해서 가벼워진 것 |
