# D-109 — travelwinners.shop 은 새 서버에 새로 짓고, 다 되면 도메인만 옮긴다

- 날짜: 2026-09-03 확정
- 갈래: infra / shop
- 종결: SHOP_RENEWAL.md O-2 (옛 라라벨 코드 처리)

## 대표님 말씀 (원문)

> 「www.여행능력자들.shop 는 지금 운영중이고 너와 새로 만들어 이 도메인 주소를 변경할거야. 새로운 서버에서 만든 걸로 이런방식으로 진행하자.」

## 정한 것

- 지금 라라벨 사이트는 **손대지 않는다.** 마지막 순간까지 그대로 살려 둔다.
- 새 사이트는 **별도 Vercel 프로젝트**로 새로 짓는다 (tw-b2b·staycurate 와 코드·배포 분리 — D-095 원칙 그대로).
- 완성·검증이 끝나면 **도메인만** 새 쪽으로 돌린다. 손님 입장에서 끊김이 없다.
- 되돌리기: 문제가 생기면 도메인을 옛 서버로 되돌리면 끝 (헌법 원칙 9 가역성).

## 비용 — 월 추가 0원

Vercel Pro 는 **사람(좌석) 단위**로 요금이 매겨지고 좌석마다 사용 크레딧이 붙는다. 프로젝트를 하나 더 만드는 것만으로는 요금이 늘지 않는다.
(출처: Vercel 공식 요금 문서, 2026-02-03 갱신본 — 좌석 $20/월 + 좌석당 $20 사용 크레딧)
DNS 변경은 Cloudflare 무료.

## 함께 처리할 것 (도메인 전환 시점에)

- `travelwinners.shop` 을 **www 없이도** 열리게 (지금은 DNS 없음 → 빈 화면)
- 한글 주소 「여행능력자들.shop」 넘김을 **301** 로 교체 (지금은 옛날식 새로고침 → 구글이 두 사이트로 볼 수 있음)
- 한글 주소 서버 https 503 정리 (301 로 바꾸면 같이 해결)
