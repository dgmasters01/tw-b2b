## 4. 🔴 미정 — 호텔 한 곳 페이지(P-09)를 만들 것인가

**안 만들 이유** — 대원칙은 「아무것도 고르게 하지 마라, [예약] 한 번에 아고다로」. 페이지가 하나 더 끼면 손가락이 한 번 더 든다.

**만들 이유** — 지금 유입 다리가 **쇼츠 하나뿐**이고 그것도 링크가 막혀 있다. 구글에서 「호텔명 + 후기」로 들어오는 손님을 받으려면 그 호텔의 페이지가 있어야 한다. 두 번째 다리가 된다.

**위험** — 아고다에서 긁어온 정보만 채운 페이지 수백~수천 장은 구글이 「알맹이 없는 페이지」로 보고 **사이트 전체에 벌점**을 준다(9장 원칙에 이미 경고돼 있음).

**클로드 추천 = ②** — 만들되 **우리 것이 있는 호텔만.** 직접 본 한 문장 + 영상 캡처가 있는 호텔만 페이지를 만들고, 그냥 딸려온 호텔은 만들지 않는다. 다만 **1차 출범에는 넣지 않는다** — 「글이 먼저」(C-24)대로 호텔이 30곳쯤 쌓인 뒤 시작.

선택지: ①안 만든다 / ②우리 것이 있는 호텔만(추천) / ③전부 만든다

## 5. 1차 출범 = 12장 + 봇 3개

손님 8장(P-01~P-08) · 관리자 4장(A-01~A-04) · 봇 B-01·B-02·B-03·B-05.

**여기까지가 「예약이 실제로 일어나는 최소 단위」다.** 회원·이벤트·메일은 2차 — 손님을 담을 그릇(호텔 목록)이 먼저 차야 회원이 모인다. 빈 사이트에 가입시킨 회원은 다시 오지 않는다.

| 디자인 규격 정본 | — | `public/shop.css` (메인·목록이 같이 읽는다) |

🔴 **주소 규칙 주의** — `cleanUrls: true` 라서 rewrite 목적지는 `/list.html` 이 아니라 **`/list`** 여야 한다(전자는 308 로 튕겨 404 가 된다. 2026-09-05 실측).
🔴 **호텔 줄·주말 가격 시트·상품 칸은 메인에서 그대로 가져온 부품**이다. 생김새를 고칠 일이 생기면 두 파일을 같이 고친다(다음에 화면이 더 늘면 부품을 별도 js 로 뽑는다).

# 9. 🔴 새 화면 만드는 표준 (2026-09-05 확정 · 대표님 지시 「구조를 정리해라, 만들 페이지가 많다」)

## 부품은 한 곳에만 있다 — `public/shop.js`

화면(html)마다 부품을 복사하면 **화면마다 모양이 갈리고 같은 일을 두 번 한다.**
2026-09-05 이전에 실제로 그렇게 되어 공유 버튼이 화면마다 달랐다. 그래서 부품을 한 벌로 합쳤다.

| shop.js 가 가진 것 | 설명 |
|---|---|
| `mountChrome({title, back, home, where, search})` | 상단바와 하단 법적 영역을 **그려준다**. 상단바 = **뒤로 ← · 홈 ⌂ · 제목 … 내 정보**. `back:false` 면 첫 화면(로고), `home:false` 면 홈만 뺀다. 🔴 **제목이 화면 안에 이미 있으면 상단바에는 넣지 않는다** — 도시 목록은 바로 아래 도시 줄에 도시가 검게 표시되므로 `title:''` 로 두고 그 자리를 홈이 쓴다(2026-09-05 대표님 지시) |
| `row(c)` | 호텔 한 줄 — 사진·TOP 배지·소개 영상 보기·찜·공유·세로 가격·차이 문구 |
| `diffLine(save, intro)` | 「12,509원 더 싸게 예약」 / 「10,472원 올랐습니다」 / 「값이 거의 같습니다」 |
| `whereHTML(cities)` · `groupByCountry` | 「어디로 가세요?」 시트 속 나라별 도시 칩 (메인·목록 공용) |
| `showAllCities()` | 「전체 보기」 — 창을 닫지 않고 그 안에서 나라 전부로 펼친다 (`/api/list?cities=1`) |
| `bindSheetDrag / bindSheets` | 시트를 손가락으로 90px 내리면 닫힌다 — 새 시트도 자동 적용 |
| `openWeekend(hid, name)` | 주말 날짜별 가격 시트 |
| `shareHotel(hid, name)` | 공유 시트(카카오톡·링크복사·문자) — 주소는 `/hotel/{번호}` |
| `toggleLike / paintLikes` | 찜(이 기기 저장) |
| `lockScroll / unlockScroll` | 시트 열 때 화면이 옆으로 밀리지 않게 |
| `setPlace(t, showInBar)` | 제목을 나중에 바꾼다. `showInBar:false` 면 브라우저 제목만 바꾸고 상단바에는 안 적는다 |
| `won / esc / img / dayTxt / shortDay / nameOf` | 글자·숫자 |

## 새 화면 만드는 순서

```html
<!-- ① 껍데기는 이 4줄이면 끝 -->
<body>
<div class="wrap"><div id="app"><div class="load">불러오는 중…</div></div></div>
<script src="/shop.js"></script>
<script>
window.PAGE = '화면이름';      // 클릭 기록에 남는다
window.SHOWDATE = true;        // 줄에 「○○ 소개 때」를 붙일지
mountChrome({ title: '약관' }); // 상단바(뒤로·홈·제목)·푸터 자동
// ② 여기서부터 이 화면만의 로직
</script>
```

- 🔴 **부품을 화면 안에 다시 쓰지 않는다.** 고칠 일이 생기면 `shop.js` 를 고친다 → 전 화면이 함께 바뀐다.
- 🔴 **디자인 규격은 `public/shop.css` 한 장.** 화면 안에 `<style>` 을 넣지 않는다.
- 🔴 새 주소는 `vercel.json` rewrites 에 추가한다. `cleanUrls` 라서 목적지는 `/list` 처럼 **확장자 없이** 적는다.

## 지금 이 표준을 쓰는 화면

메인 `/` · 도시·나라 목록 `/{나라}/{도시}` · 검색 `/search` · 호텔 한 곳 `/hotel/{번호}` · 내 정보 `/likes` · 상품 목록 `/{나라}/{도시}/products`

## 앞으로 만들 화면도 같은 틀로

약관 · 개인정보 처리방침 · 404 · 쇼츠 등록(A-01) · 오늘 현황(A-02) · 호텔 관리(A-03) · 봇 상태(A-04)
