### 🔴 5-B. 짧은 추적 주소 — 규격 정본 (D-117 · 2026-09-06)

```
gohpik.com / {사업} / {코드}          예) gohpik.com/h/cj4bng
              │        └─ 6글자 · 알파벳 abcdefghjkmnpqrstuvwxyz23456789
              │           🔴 0 O 1 I L 을 뺐다 — 전화로 불러주거나 손으로 적을 때 한 글자만 틀려도 링크가 죽는다
              └─ r 스튜디오(기존·건드리지 않음) · h 여행능력자들 · b 블로그 · c CEYLON · p 상품 · e 이벤트
```

**🔴 바꾸지 않는 세 가지**
1. **한 번 정한 사업 글자는 바꾸지 않는다** — 이미 나간 영상 설명란은 고칠 수 없다
2. **코드는 재사용하지 않는다** — 다른 것을 가리키면 과거 통계가 통째로 거짓이 된다
3. **주소에 정보를 붙이지 않는다** — `?src=&v=&won=` 처럼 붙이면 복사하다 잘려 기록이 날아간다. 코드 하나가 창고에서 아홉 가지를 가리킨다(사업·종류·호텔·**주민번호**·상품·숙박일·화면·**채널**·**캠페인**)

**흐르는 길** `gohpik.com/h/{코드}` →(tw-b2b 302) `travelwinners-shop…/s/{코드}` →(해석) `/go/{호텔}?d=&src=&p=&lc={코드}` → 아고다
🔴 **기록은 `/go`·`/pgo` 한 곳에서만 한다.** `/s` 는 넘기기만 한다 — 두 곳에서 기록하면 숫자가 갈라진다.
🔴 **tw-b2b 의 302 는 permanent=false 로 둔다.** 301 로 두면 브라우저가 영구 저장해, `travelwinners.shop` 이 새 프로젝트로 옮겨온 뒤에도 옛 목적지로 간다.
🔴 **도메인 이전 시 할 일**: tw-b2b `vercel.json` 의 `/h/:code` 목적지를 `https://travelwinners.shop/s/:code` 로 한 줄 교체.

**같은 조건이면 같은 코드를 돌려준다**(`api/link.js` 가 먼저 찾아본다) — 같은 링크가 둘이면 통계가 갈라진다.
**봇·프리페치·`?check=1` 은 실적에서 뺀다**(`api/go.js` · 스튜디오 `api/r.js` 규칙 이식). 카톡이 링크를 미리 훑는 것을 세면 공유 100건에 가짜 클릭 100건이 얹힌다.

2026-09-06 실측: 발급 `cj4bng` → 재요청 시 같은 코드(reused) → `gohpik.com/h/cj4bng` → 아고다 9/20~9/21 2인 1박 · CID 1919025 도달 · 클릭 장부에 링크코드·방문자·기기·나라 기록 확인. 기존 `/r` 과 gohotelwinners 무사.

**호텔 요금 구조 (조사 결과)** — 호텔은 공표요금(랙 레이트) 위에 **BAR(그날의 최선 요금)** 를 둔다. 계절별 수요를 분석해 **성수기·비수기 요금을 미리 준비**하고, 다른 요금제는 BAR 대비 «비율»로 자동 산출한다.

**1년치 확대 (예정)** — 지금 3개월 주말 52일 → 1년 주말 208일. 한 바퀴 4,108회 → **16,432회 ≈ 이틀**. 돈 0원.
🔴 **오류 거르는 규칙(①~④)을 세운 뒤에 넓힌다.** 먼저 넓히면 엉터리 값도 4배로 늘어난다.

| 후기 시간축 | **없음** — `reviews_prev` 31,499곳 전부 빈칸 | `shop_hotel_review` 신설 · 매일 담음 |

🔴 **`review_delta` 가 3,563곳 전부 0이던 진짜 원인** — 후기 수를 **한 번만** 받아 「지난번 값」이 없어 뺄셈이 불가능했다. 아고다 Lite API 는 `reviewCount`·`reviewScore` 를 **이미 주고 있었는데 버리고 있었다**(조식·정가와 같은 패턴 §9). 담기 시작 = **호출 0회 증가 · 월 요금 0원.**

**표 세 개**

| 표 | 무엇 | 누가 채우나 |
|---|---|---|
| `shop_hotel_review` | 호텔별 후기 수·평점의 **시간축** (호텔×날짜 한 줄) | 가격 수집 일꾼 (10분마다, 값과 함께) |
| `shop_hotel_type` | **호텔 딱지** 22,911곳 — 지역·값대·성급·숙소종류·신상·브랜드·후기수·후기점수 | 취향 학습 일꾼 (하루 1회) |
| `shop_taste` | **손님 취향 점수** — 손님×축×값 한 줄 | 〃 |

**축(타입) 8가지** — `area` 지역덩어리 · `band` 값대(1~5) · `star` 성급 · `kind` 숙소종류 · `brand` 브랜드 · `city` 도시 · `month` 갈 달 · `seen` 이미 본 호텔

🔴 **지역은 «이름»이 아니라 «좌표 덩어리»로 잡는다** — `area_key = 도시:위도칸:경도칸`, 격자 **0.02도(약 2.2km)**.
실측: 도쿄 1,993곳 → 128칸(호텔 5곳 이상 든 칸에 94%) · 방콕 2,537곳 → 219칸(92%) · 마닐라 1,429곳 → 82칸(94%).
이름은 그 덩어리 안 이웃에게서 물려받고, **아무도 모르면 비워 둔다**(`HOTEL_MATCH` 원칙 ④). **이름이 없어도 추천은 된다** — 손님이 누른 것을 세는 데는 번호면 충분하다.
🔴 **지도 창구를 부르지 않는다.** 좌표는 이미 우리 것이다 — **호출 0회 · 0원.**

**학습 규칙 (인공지능이 아니라 셈이다)**
무게 = 열람 1 · 예약클릭 3 · 공유 4 · **찜 5 · 장바구니 5** · **14일 반감기**(옛 행동은 저절로 옅어진다).
창고 함수 `shop_learn_taste(60)` 한 곳에서만 계산한다. 🔴 **화면에서 계산하지 않는다**(§10 · 실측 502).

🔴 **값대는 «도시 안에서» 5단계로 자른다**(`ntile(5) over (partition by city_slug)`). 나라마다 물가가 달라 절대 금액으로 자르면 방콕 5성이 도쿄 1성과 같은 칸에 들어간다.

**실측 2026-09-07** — 호텔 딱지 22,911곳(지역 100% · 이름 75% · 신상 3,683 · 값대 4,437) · 취향 124줄 · 일꾼 **3.9초** · 후기 오늘치 4,150곳 저장(아고다 응답 전부 200 · 차단 0 · 호출 99회로 **증가 없음**).

🔴 **아직 못 믿는 것 — 첫 후기 비교(9/5 명부 ↔ 9/7 아고다)는 축이 다르다.** 3,745곳 중 3,708곳이 늘었고 평균 +239 인데, 이틀 만에 나올 수 없는 크기다. **명부의 후기 수가 언제 잰 값인지 모른다.** → 아고다↔아고다로 두 번 잰 **내일부터**가 진짜 값이다. 그전에는 `review_delta` 를 순서 재료로 쓰지 않는다(§8-④ 반복 관측 규칙과 같은 원리).

대표님: *«글로벌 서비스는 어떤 방식으로 하는지 파악해서 우리도 우리에게 맞게 설계하는게 맞음. 이런걸할때는 자료부터 조사해»*

**읽은 자료**

**우리 설계와 대조한 결과**

| 업계가 실제로 하는 것 | 어제 우리 설계 | 고친 것 |
|---|---|---|
| 🔴 **여행은 «영구 콜드스타트»** — 연 1~2회라 «먼 과거 이력은 대개 쓸모없다»(Booking.com) | 우연히 같은 방향(14일 반감기) | 유지. 다만 **14일은 짐작값임을 명시** |

| 🔴 **Uncanny Valley** — 너무 잘 맞히면 손님이 불편해하고 **매출이 떨어졌다**(실측) | 제한 없음 | **`max_shift=0.30`** — 개인 점수가 순서를 바꿀 수 있는 폭을 30%로 묶는다 |
| 🔴 **Proxy Over-optimization** — 클릭률만 올리려다 «비슷한 호텔»만 추천해 손님이 선택 마비에 빠지고 **전환이 떨어졌다** | 「닮은 호텔 일꾼」이 정확히 이 함정 | 닮은 곳만 채우지 않는다. 다양성을 함께 넣는다 |
| 🔴 **오프라인 성능 향상 ≠ 매출** (실측 상관 **-0.1**) | — | 「순서가 좋아졌다」를 성과로 삼지 않는다. **예약 클릭으로만 판정** |
| 🔴 **지연 30% 증가 = 전환 0.5% 감소**(실측) | 밤에 미리 계산 | 방향 일치. 유지 |
| **모델 비교는 «두 방식이 다른 답을 낸 손님»만 본다** — 아니면 신호가 묽어진다 | — | 순서를 켤 때 이 방식으로 잰다 |
| **동행 맥락**(커플·가족·친구·혼자 / 레저·출장)을 추측한다 | 없었다 | 자료가 없다. **지어내지 않고 비워 둔다** |

**고친 것 — 숫자를 코드에서 빼냈다: `shop_taste_config`**
