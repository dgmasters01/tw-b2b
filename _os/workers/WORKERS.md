# WORKERS — 우리 일꾼 전체 (사람이 읽는 판)

> 🔴 **이 파일은 손으로 고치지 않는다.** `_os/workers/registry.json` 을 고치고 `python3 _os/workers/build.py` 를 돌리면 다시 만들어진다.
> 마지막 갱신 2026-09-06 · 서비스 5곳 · 일꾼 90명

## 이 문서를 읽는 법

```
일꾼 = 우리가 시키지 않아도 스스로 일하는 프로그램이다.
사람으로 치면 — 시계가 «몇 시다» 하고 깨우면, 일꾼이 나가서 일하고, 결과를 창고에 적어 둔다.

각 일꾼은 네 가지로 적는다
  어디서   어느 서비스의 어느 시계가 이 일꾼을 깨우나
  언제     얼마나 자주 나가나
  무슨 일  초등학생도 알 수 있는 한 문장
  어떻게 확인  일한 결과가 어디에 남나 / 대표님이 어느 화면에서 보나
```
